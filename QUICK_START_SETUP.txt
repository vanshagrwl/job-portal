Job portal — Render (API) + Vercel (frontend)
═══════════════════════════════════════════════════════════════════

URLs (adjust if your service names differ):
  Frontend: https://job-portal-orcin-eight.vercel.app  (or dreamai-job.vercel.app)
  Backend:  https://job-portal-backend.onrender.com
  GitHub:   https://github.com/vanshagrwl/job-portal

───────────────────────────────────────────────────────────────────
STEP 1 — Render backend
───────────────────────────────────────────────────────────────────

1. https://dashboard.render.com → New → Web Service (or Blueprint from repo + render.yaml)
2. Build: npm install     Start: npm start
3. Environment:
     MONGODB_URI = (your MongoDB Atlas connection string)
     JWT_SECRET  = (long random secret)
4. Deploy, then copy your public URL (e.g. https://job-portal-backend.onrender.com)

───────────────────────────────────────────────────────────────────
STEP 2 — Vercel frontend
───────────────────────────────────────────────────────────────────

1. https://vercel.com/dashboard → your project → Settings → Environment Variables
2. VITE_API_URL = https://YOUR-RENDER-HOST.onrender.com/api
3. Redeploy production

───────────────────────────────────────────────────────────────────
Verify
───────────────────────────────────────────────────────────────────

  curl https://YOUR-RENDER-HOST.onrender.com/health
